# 🍩 dough

A personal finance tracking cli and tui.

## features

* track balances of multiple accounts over time
* track salary over time
* track progress towards financial goals

## install

```bash
```
curl -sSL https://raw.githubusercontent.com/paullj/dough/main/install.sh | sh
```
```
